MERN Food Ordering App

A full-stack food ordering web application built using the MERN stack with secure Stripe payment integration. The platform allows users to browse food items, place orders, and enables admins to manage products and orders efficiently.

🚀 Features
👤 User Side
- Browse available food items
- Add items to cart
- Secure checkout with Stripe payment
- Place orders easily
- Responsive UI
🛠️ Admin Panel
- Add new food items
- Delete existing items
- View all orders
- Confirm and manage orders
🧰 Tech Stack
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Payment Gateway: Stripe
